# AprendIA 🚀

Plataforma interativa  de letramento digital e aprendizado de tecnologia através de trilhas curtas e adaptativas.

## ✨ Funcionalidades

- **Onboarding e Nivelamento Dinâmico**: Teste de nivelamento inicial com perguntas de múltipla escolha para determinar automaticamente o ponto de partida ideal na trilha.
- **Trilha Adaptativa de Aprendizado**: Módulos do nível básico ao avançado (Informática básica, segurança na internet, planilhas, dashboards e programação).
- **Gameficação Completa**:
  - Pontuação por experiência (**XP**)
  - Sequência de dias ativos (**Streak**)
  - Sistema de desbloqueio progressivo de lições
  - Conquistas e selos de competências adquiridas
- **Intervenções Inteligentes (IA)**: Feedbacks contextuais e recomendações de revisão com base no desempenho do usuário.
- **Visualização de Progresso e Perfil**: Acompanhamento percentual de conclusão e competências dominadas.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Armazenamento de Sessão**: `sessionStorage` para persistência do estado da jornada
- **Backend / Servidor**: Node.js & Express (opcional para execução local ou deploy)

## 🚀 Como Executar

### Opção 1: Execução direta no navegador
Basta abrir o arquivo `index.html` em qualquer navegador web moderno.

### Opção 2: Com Node.js
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor:
   ```bash
   npm start
   ```
3. Acesse `http://localhost:3000` no seu navegador.
